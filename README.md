# RoboMood — موزیک‌پلیر احساسی

موزیک‌پلیر فارسی RTL با رابط شیشه‌ای، ربات انیمیشنی، صف پخش، کنترل صدا و تحلیل لحظه‌ای صوت.

## اجرا روی GitHub Pages
1. فایل‌های این پوشه را در ریشه یک مخزن GitHub آپلود کنید.
2. از **Settings → Pages** گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه `main` و پوشه `/ (root)` را ذخیره کنید.
4. لینک منتشرشده را با HTTPS باز کنید.

## نصب
- **Android / Chrome:** سایت را باز کنید و از منوی مرورگر گزینه Install app یا Add to Home screen را بزنید.
- **Desktop / Chrome یا Edge:** روی آیکون نصب در نوار آدرس کلیک کنید یا از منوی مرورگر Install app را بزنید.

## امکانات
- انتخاب چند فایل صوتی از دستگاه
- پخش/مکث، قبلی/بعدی، جست‌وجو در زمان آهنگ، صدا، shuffle و تکرار
- انیمیشن ربات با حالت‌های آرام، شاد، رویایی و پرقدرت
- تحلیل محلی انرژی و تغییرات فرکانسی با Web Audio API
- سرویس‌ورکر برای پوسته آفلاین پس از بارگذاری اولیه

## محدودیت‌ها
- مرورگر نمی‌تواند بدون اجازه به کل موسیقی‌های گوشی یا برنامه‌های دیگر دسترسی پیدا کند؛ آهنگ‌ها را باید از داخل پلیر انتخاب کنید.
- تحلیل فعلی از شدت و تغییرات طیفی صدا برای تخمین حالت استفاده می‌کند؛ هوش مصنوعی تشخیص‌دهنده ژانر یا احساس معنایی آهنگ نیست.
- فایل‌های انتخابی پس از بسته‌شدن صفحه به‌طور خودکار در صف پخش باقی نمی‌مانند.
- PWA از طریق `file://` قابل نصب نیست؛ باید با HTTPS یا localhost اجرا شود.
