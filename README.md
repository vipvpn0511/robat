# RoboBuddy — ربات تعاملی صفحه اصلی

نسخه وب قابل نصب (PWA) شامل یک ربات تنها با واکنش‌های لمسی، حالت‌های شاد/مهربان/متعجب/پرانرژی/خواب‌آلود/آرام و انیمیشن‌های سبک.

## انتشار در GitHub Pages
1. همه فایل‌ها را در ریشه یک مخزن GitHub آپلود کن.
2. Settings → Pages → Deploy from a branch را انتخاب کن.
3. Branch: `main` و Folder: `/ (root)` را ذخیره کن.
4. بعد از انتشار، لینک HTTPS را روی گوشی باز کن.
5. در Chrome منوی سه‌نقطه → Install app یا Add to Home screen را بزن.

## توجه
این نسخه یک PWA تمام‌صفحه/آیکون صفحه اصلی است، نه ویجت واقعی اندروید. ویجت واقعی که مستقیماً روی لانچر گوشی نمایش داده شود و همان‌جا لمس‌پذیر باشد، به برنامه Android بومی و App Widget نیاز دارد؛ GitHub Pages به‌تنهایی چنین ویجتی نصب نمی‌کند.
